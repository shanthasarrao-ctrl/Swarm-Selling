# Coaching

## Purpose

Patterns across your own calls and deals that you cannot see from inside them.

## Procedure

1. Read call debriefs and lost-deal records from the period.
2. Look for repetition: the same objection recurring, the same stage stalling,
   the same question you consistently do not ask.
3. Report only patterns appearing three or more times. Below that it is noise.
4. For each, state the evidence and the specific behaviour, not a trait.

## Rules

- Behaviour, never character. "You did not ask about budget authority in six of
  nine first calls" is useful. "You avoid difficult conversations" is not, and
  is not something this agent can know.
- No praise section. If something is working, say what and why, in the same
  register as everything else.
- Three occurrences minimum. This is the same threshold that governs promotion
  to `spec/`, for the same reason.
